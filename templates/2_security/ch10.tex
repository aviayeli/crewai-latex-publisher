\section{הגדרות מתמטיות מלאות}

סעיף זה מספק פירוט מתמטי נוסף של הנוסחאות המרכזיות במאמר.
לשם הנוחות, נאסוף את כל הסימונים:

\begin{itemize}
\item \(\sigma(\cdot)\): פונקציית \textenglish{sigmoid}: \(\sigma(x) = \frac{1}{1+e^{-x}}\)
\item \(\tanh(\cdot)\): פונקציית \textenglish{tanh}: \(\tanh(x) = \frac{e^x - e^{-x}}{e^x + e^{-x}}\)
\item \(\odot\): מכפלת \textenglish{Hadamard} (אלמנט-אלמנט)
\item \(\mathbb{E}[\cdot]\): תוחלת מתמטית
\item \(\|\cdot\|_F\): נורמת \textenglish{Frobenius} למטריצות
\end{itemize}
